# Domain docs

This repository uses a single-context layout:

- CONTEXT.md at the repository root: domain vocabulary and model.
- docs/adr/: architectural decision records.

## Before exploring

Read CONTEXT.md and ADRs relevant to the area being explored.
If these files are absent, proceed silently. The domain-modeling
skill creates them when terms or decisions are resolved.

## Vocabulary

Use the terms defined in CONTEXT.md in issues, proposals,
hypotheses, and tests. If a needed concept is missing, reconsider
the wording or note the gap for domain-modeling.

## Decisions

Explicitly flag proposals that contradict an existing ADR,
identify the ADR, and explain why the decision should be revisited.
